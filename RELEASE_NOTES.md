## v1.1.1

- Background **Enable** starts off on first use. Reopening the same WebUI in the same browser profile restores the last setting you selected.
- **Enable Style Boost** remains independent.

### 日本語

- Background の **Enable** は初回OFFです。同じブラウザープロファイルで同じWebUIを開き直すと、最後に選んだ状態を復元します。
- **Enable Style Boost** は個別に切り替えられます。
