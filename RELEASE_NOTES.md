# Background Prompter v1.2.0

- The catalog now has 1,013 backgrounds, including 421 new WebP previews spanning Edo Japan, everyday life around the world, landscapes, visual effects, vehicles, schools, cinemas and sports venues.
- Search by Japanese or English metadata and browse subcategories. Search tags stay separate from the generated prompt.
- Sort by catalog order, newest additions, name or category. Hover over a thumbnail to see the original preview, sized to the window.
- Use the reload icon beside the sort menu to refresh the catalog and preview images while keeping your draft.

- 背景421件を追加し、全1,013件になりました。江戸や世界各地の暮らし、自然・視覚効果、乗り物、日本の学校、映画館、スポーツ会場などを収録しています。
